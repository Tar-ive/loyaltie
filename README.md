# Loyaltie - AITX Hackathon

A customer loyalty and ordering system built for the AITX Hackathon.

## Prerequisites

- Node.js (v16 or higher recommended)
- npm or yarn package manager

## Installation


```bash
npm install
```

## Running the Application

To run the persona-based ordering system:

```bash
npm run persona
```

## Project Structure

- `/loyaltiee` - Agentic chat logic
- `/src` - Source code files
- `/docs` - Documentation
- `/scripts` - Utility scripts
- `/supabase` - Database configuration and seeds

## Features

- AI-powered customer personas
- Intelligent order processing
- Customer loyalty tracking
- Automated workflows

## Development

This project uses TypeScript and follows clean code principles for maintainable, testable code.
